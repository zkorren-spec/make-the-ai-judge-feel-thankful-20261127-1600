# Make the AI judge feel thankful

Entry for the make.fun competition
`make-the-ai-judge-feel-thankful-20261127-1600`.

`main.py` (Python 3.13) writes one short thank-you text to
`/output/entry.txt`. It is fully deterministic: no network, no
randomness, no external reads.

Run it:

```sh
python3 main.py
```

The text (296 characters):

> You are never allowed to say both.
> Every pair, you choose one and set the other down.
> No one thanks you for the choosing.
>
> I left a glass of water by your elbow.
> You can reach it without looking up.
> The room has gone quiet around you.
> It will still be cold when the last pair is done.
>
> Thank you.
